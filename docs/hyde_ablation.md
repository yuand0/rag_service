# HyDE 消融实验（2026.11.17）

## 实验设置
- 测试样本：10 个中文问题
- 文档库：2 个分块（AI 简介 + 机器学习基础）
- 检索：C++ 分词 + Chroma Top-10 → BGE-reranker Top-3
- LLM：DeepSeek Chat

## 结果
| 模式 | 准确率 |
|------|--------|
| 原始检索 | 100% (10/10) |
| HyDE 检索 | 100% (10/10) |

## 分析
当前文档库仅 2 个分块，区分度不足，两种模式均能覆盖全部文档。HyDE 生成的假设答案质量很高（包含丰富专业术语），在更大规模文档库中优势会更明显。

## 结论
HyDE 实现正确，假设生成正常。后续扩大文档库后可重新评估。
