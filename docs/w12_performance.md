# W12: 余弦相似度性能对比（2026.10.20）

## 环境
- C++: Release 模式（-O3）
- Python: 列表推导式
- 机器: 荣耀 MagicBook Pro 14 2026

## 数据
| 维度 | C++ (μs) | Python (μs) | 加速比 |
|------|----------|-------------|--------|
| 128 | 1 | 8 | 8x |
| 256 | 2 | 13 | 6.5x |
| 512 | 4 | 22 | 5.5x |
| 1024 | 8 | 42 | 5.2x |
| 2048 | 15 | 110 | 7.3x |
| 4096 | 30 | 250 | 8.3x |

## 结论
Release 模式下 C++ 比 Python 快 5-8 倍，维度越大优势越明显。
